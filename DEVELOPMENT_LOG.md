### Important Decisions

**Decision: Singleton service pattern**
> Each AI service (image, audio, video) is a singleton with a `get_instance()`
> class method. This avoids re-loading large models on every request and
> keeps the codebase testable (the singleton can be replaced in tests).

**Decision: JSON flat-file evidence store**
> For Phase 1, evidence observations are stored as a JSON array per case
> in `data/<case_id>.json`. This requires no database setup and is easily
> readable by students. A migration to SQLite or another store can be done
> transparently later since the interface is abstracted through `FusionService`.

**Decision: Lazy model loading**
> AI models (RT-DETR, BLIP, CLIP, Whisper) are not loaded at import time.
> They are loaded on first use OR explicitly via `load_models()`. Missing
> checkpoints do not trigger downloads by default; model-download opt-in must
> be explicitly enabled. The Flask app can start without loading model weights.

**Decision: Groq for LLM**
> Groq is an optional external inference service. Local chat remains available
> when it is not configured; live service behavior has not been verified here.

**Decision: Magic-byte validation**
> In addition to extension checking, supported uploads receive best-effort
> signature checks. This is not malware scanning or comprehensive file
> validation; deep forensic file analysis is out of scope.

**Decision: No auto-install of models during init**
> As required by the project rules, no model weights are downloaded on startup.
> Model weights are local-only by default. Downloads require explicitly
> enabling `ALLOW_MODEL_DOWNLOADS`; cached weights may be used without download.
> The Whisper model (`base`, ~74 MB) and RT-DETR (`r18vd`, ~66 MB) are the
> smallest variants in their respective families.
